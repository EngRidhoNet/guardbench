# Changelog

All notable changes to GuardBench will be documented here. The project follows [Semantic Versioning](https://semver.org/).

## [Unreleased]

### Planned

## [0.1.0-alpha] - 2026-11-01

### Added

- Three-class `allow`, `block`, and `escalate` evaluation engine.
- JSON/CSV datasets with immutable persisted versions.
- Mock, Python-callable, and secured HTTP target adapters.
- Classification, guardrail-failure, coverage, and latency metrics.
- Run comparison and CI quality gates with JSON/JUnit reports.
- FastAPI service, SQLite/PostgreSQL persistence, and Alembic migrations.
- React investigation dashboard and Docker Compose deployment.
- Credential-free synthetic fintech benchmark.
